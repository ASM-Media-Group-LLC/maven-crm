# Backstage manda el equipo — se movió

Esta guía ahora es genérica, para la plataforma de cualquier agencia (Backstage fue la primera):
**[docs/conectar-plataforma.md](./conectar-plataforma.md)**.

Ahí está todo lo que antes vivía aquí (`POST /equipo/sync`, las reglas, la respuesta, el ensayo y
el interruptor del dueño, y el prompt para quien programa la plataforma), más lo nuevo del
11/11/2026: los roles que manda la plataforma, los pendientes que el dueño aprueba o descarta,
`GET /equipo`, `GET /equipo/horas`, `GET /equipo/notas` y los avisos por webhook.
